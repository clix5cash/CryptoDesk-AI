# Public examples

Run the examples after `pnpm build --force`:

```sh
pnpm example:ai
pnpm example:morning-meeting
pnpm example:ritual
pnpm example:runtime-safety
```

`pnpm examples` runs the four explicit developer-invoked examples in sequence.
They use public package APIs and deterministic synthetic/local inputs. They do
not provide live data, credentials, wallet access, trading, recommendations,
autonomous behavior, or production Ritual execution. External Ritual
verification remains **INCONCLUSIVE**.
