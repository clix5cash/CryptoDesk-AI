# @cryptodesk-ai/morning-meeting

Provider-neutral Morning Meeting application contracts.

The package defines deterministic meeting requests, reports, market views,
sections, evidence references, analytical bias, and risk classifications. It
depends only on Market Intelligence contracts and does not fetch provider data,
run indicators or signals, call AI models, persist reports, or schedule work.

`MorningMeetingReport` is structured input for a future narration layer; it is
not an AI-generated prose artifact.
