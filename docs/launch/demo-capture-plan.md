# Demo screenshot and video capture plan

This is a reproducible capture plan, not a claim that unavailable data is live.
Use a clean browser/session and the already-built application only.

## Shot sequence

1. Production landing page: show product identity and public URL.
2. `/app` overview: show read-only posture and domain navigation.
3. `/app/market`, `/app/news`, `/app/portfolio`, and `/app/morning-meeting`:
   show honest unavailable/unknown states and authority labels.
4. Repository README: show Quick Start commands and prerequisites.
5. Terminal: run `pnpm demo` and `pnpm examples`; show deterministic synthetic
   output and bounded lifecycle labels.
6. Optional evidence frame: show test summary and static route build output.

## Must not appear

Do not show credentials, environment files, wallet addresses, private keys,
personal portfolio data, private endpoints, local absolute paths, raw provider
errors, fabricated live prices/headlines/holdings, or unsupported autonomy and
Ritual-success claims.

## Short-video structure

Use a 30–60 second sequence: identity (5s), application routes (15s),
Quick Start/examples (20s), safety boundaries and contribution invitation
(10s). Caption unavailable states explicitly; do not call them live.

No screenshots, video files, browser dependencies, or external publication are
created by this sprint.
