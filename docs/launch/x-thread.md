# X/Twitter launch thread (draft)

1. CryptoDesk AI is an open-source TypeScript architecture for deterministic
   market, news, portfolio, and Morning Meeting intelligence—with explicit
   boundaries around AI and execution.

2. The long-term model is **Observe → Think → Remember → Decide → Act**. It is
   a responsibility map, not a claim that the system currently runs
   autonomously.

3. Market, News, Portfolio, and Morning Meeting keep their own authority.
   Provider Federation retains provenance, freshness, availability, and
   disagreement instead of inventing a universal winner.

4. Intelligence Composition combines already-produced domain results while
   preserving domain identity and local uncertainty. Composition is not a
   canonical truth layer or consensus engine.

5. AI remains descriptive and non-authoritative:
   `untrusted_model_execution → untrusted_candidate_interpretation →
non_authoritative_interpretation`.

6. Runtime Safety is finite: explicit request → candidate → authorization →
   single-attempt permission → at-most-one execution → terminal result → stop.

7. Developers can clone the repository, run the Quick Start, and execute four
   public local examples without credentials or live providers. Technical
   feedback is welcome through issues, pull requests, and Discussions.

8. Read the [Technical Paper Public Edition](../technical-paper-public-edition.md)
   and explore <https://github.com/clix5cash/CryptoDesk-AI>. No token,
   investment, custody, or autonomous-trading claim is made. External Ritual
   verification remains **INCONCLUSIVE**.
