# GitHub launch announcement (draft)

CryptoDesk AI is an open-source TypeScript monorepo for deterministic market,
news, portfolio, and Morning Meeting intelligence with explicitly bounded AI
and runtime integration.

The public repository now includes:

- deterministic Market, News, Portfolio, and Morning Meeting contracts;
- provider-neutral Federation and cross-domain Intelligence Composition;
- a read-only MVP application at `/app` and its domain routes;
- a verified Developer Quick Start and executable public examples;
- structured issue forms, pull-request guidance, security reporting, Code of
  Conduct, and GitHub Discussions.

The architecture is organized around **Observe → Think → Remember → Decide →
Act** as a long-term model, not a claim of current autonomy. AI output follows
`untrusted_model_execution → untrusted_candidate_interpretation →
non_authoritative_interpretation`. Runtime Safety requires an explicit request,
authorization, one bounded attempt, a terminal result, and stop.

Start with the [Developer Quick Start](../../README.md#developer-quick-start),
then try the [public examples](../../examples/README.md). Read the [Technical
Paper Public Edition](../technical-paper-public-edition.md) for implementation
evidence and boundaries. The public site is available at
<https://cryptodesk-ai.vercel.app>.

Contributors are invited to open focused issues or discussions and propose
small, testable changes. Please do not include credentials, wallet/private-key
material, private endpoints, or personal financial data. CryptoDesk AI does
not provide autonomous trading, custody, asset transfer, investment advice, or
guaranteed results. External Ritual verification remains **INCONCLUSIVE**.
